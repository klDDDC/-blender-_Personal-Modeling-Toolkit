# Changelog

## 1.8.1 - 2026-08-04

- 「清理材质槽」新增场景级同名族材质统一：把 `Material.001/002` 这类仅数字后缀不同的重复材质统一到无后缀基础材质，所有物体（含未选中）的材质槽自动重定向并合并重复槽，再删除多余副本（含假用户或已赋给物体的；链接库材质不参与，Asset 材质只重定向不删除）。解决反复导入同名资源导致 `.001` 材质堆积的问题。

## 1.8.0 - 2026-08-02

- 材质色块改为可点击操作入口：弹窗可搜索全部材质，并将当前选中的所有网格模型中与源材质数据块精确相同的槽替换为目标材质；槽顺序、面材质索引、UV、对象选择和活动对象保持不变。
- 新增“选中该材质的所有面”：按精确数据块跨当前选中网格工作，Object Mode 自动进入多物体 Edit Mode，已在 Edit Mode 时保持模式，共享 Mesh 只处理一次。
- “清除材质槽”和“整理材质”统一使用安全清理：只删除已确认数字后缀族中真正无用户的本地材质；Fake User、Asset、链接库及任何仍被引用的材质均受保护，不再按名称强制重定向独立材质。
- 快捷键改为版本化 JSON 持久化，稳定键由 Operator ID 和固定参数生成；支持键盘/鼠标、修饰键、启用状态和重复触发，编辑后自动防抖保存、失败自动重试，并保留立即保存、重置和状态显示。
- 版本、安装验证、开发文档和评估报告同步更新至 1.8.0。

## 1.7.9 - 2026-08-01

- 修复「斜向拉直」手动拖拽模式的报错：鼠标方向判断使用了错误的 `length_sq` 属性，改为 `length_squared`。

## 1.7.8 - 2026-08-01

- 修复「斜向拉直」手动拖拽模式的崩溃：鼠标方向计算使用了错误的 RegionView3D 获取方式，现改为从 3D 视图窗口区域的 `region.data` 读取视图矩阵，并增加兜底保护。

## 1.7.7 - 2026-08-01

- 「斜向拉直」升级为 FFD 式手动拖拽控制：选中顶点后点击按钮，在 3D 视图中拖动鼠标即可实时调整拉直方向（顶点实时预览 + 橙色方向参考线），左键确认、右键/ESC 取消；设置中仍可选用自动（最远两点）、沿活动边、X/Y/Z 轴、自定义角度等预设方向。

## 1.7.6 - 2026-08-01

- 新增「斜向拉直」：编辑模式下选中顶点（≥3 个），一键投影到最远两点连成的直线上，等效于 3ds Max FFD 2x2x2 的斜向拉直效果。入口：建模工具面板按钮、编辑模式右键菜单；可在快捷键面板绑定按键。

## 1.7.5 - 2026-08-01

- 修复首次切换布局时区域分配错误：`area_split` 后新区域坐标尚未更新，按坐标排序会把原 3D 视图误判为编辑器区域并转换。现在改用指针识别，新分割出的区域作为 UV/着色器编辑器，原 3D 视图完整保留。

## 1.7.4 - 2026-08-01

- 场景级统一同名族材质后，自动合并所有物体（含未选中物体）中指向同一材质的重复槽位：统一 `Material.001 -> Material` 时产生的多槽同材质（如 `[Metal, Metal]`）会被合并为单个槽，面的材质索引同步修正。

## 1.7.3 - 2026-08-01

- 「清除材质槽」「整理材质」「合并重复材质」新增场景级同名族材质统一：扫描全部材质，将仅有 `.001/.002` 等数字后缀的重复材质（如 `Material.001`）统一到不带后缀的基础材质，所有物体（无论是否选中）的材质槽自动重定向，并删除多余的重复材质（带假用户或已赋给物体的也会一并清理，链接库材质除外）。

## 1.7.2 - 2026-07-31

- 修复「清除材质槽」仍无法清理带假用户标记的未使用材质（如 UI 新建材质产生的 `Material.001`）：现在删除所有无真实引用（`users - use_fake_user <= 0`）的材质，链接库材质除外。
- 修复快捷键修改后重启丢失：点击「保存快捷键」/「重置快捷键」时立即调用 `bpy.ops.wm.save_userpref()` 强制写入磁盘。

## 1.7.1 - 2026-07-31

- 修复「清除材质槽」不会清理场景中未被使用的孤儿材质（如自动生成的 `.001`）：现在清除后同步删除 `users==0` 的材质数据，并刷新重复材质缓存。
- 修复快捷键在面板修改后不持久化、重启丢失的问题：新增 AddonPreferences `shortcut_overrides`（JSON）存储键位，注册时自动恢复；快捷键面板新增「保存快捷键」「重置快捷键」按钮及操作提示。

## 1.7.0 - 2026-07-27

- 重新设计 3D 视图侧栏：移除重复二级折叠和内嵌框，所有功能区使用 Blender 原生一级 Panel。
- 快捷键改为独立且默认折叠的一级面板。
- 法向角度删除 60°，将 180°/30°/90°、只读自定义值和自定义对话框按钮整合为单行。
- 建模操作改为固定两列排列，保留 UV 命名、合并距离和角度阈值设置入口。

- 按材质名称族折叠多物体材质列表，保留独立材质数据块。
- 将材质名称放到主行，避免操作图标遮挡名称。
- 材质色块改为首次分配后持久不变的 50 色高区分度循环调色板，并移除单材质名称下方的操作图标行。
- 将法向角度控件移到建模工具顶部，移除多物体材质组统计行。
- 按用户要求完整移除 Flatten U/V 与 Pin/Unpin 功能。
- 清除自定义分裂法向和 tangent 缓存后再应用 Smooth by Angle。
- 修复顶点颜色、材质 ID、Edit Mode UV 和顶点组筛选的状态与数据处理。
- 增加 Object/Edit Mesh 右键菜单入口、可复现 ZIP 打包与带权限继承/失败回滚的本地安装脚本，并移除发布批处理中的硬编码路径和直接推送行为。

正式发布标签：`v1.7.0`。Blender 集成测试仍需在目标 Blender 版本矩阵上运行。
